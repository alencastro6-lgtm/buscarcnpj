# BUSCAR_CNPJ

Aplicação simples para consultar CNPJ e salvar os dados em TXT.

## Uso

```powershell
python main.py
```

## Recursos

- Validação de CNPJ
- Interface GUI com histórico de consultas
- Exporta dados para TXT
- Copia todos os campos para o clipboard
- Cache local em SQLite
